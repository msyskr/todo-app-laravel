# Todoアプリ（Laravel）

## URL
https://todo-app-laravel-3.onrender.com/tasks

## 概要
Laravelを用いてTodo管理アプリを作成しました。

## 機能
- タスク追加
- 期限設定
- 完了（Done）
- ゴミ箱機能
- 復元機能
- ゴミ箱の完全削除

## 使用技術
- Laravel
- Tailwind CSS
- PostgreSQL
- Docker
- Render（デプロイ済み）

## 工夫した点
- ゴミ箱機能を実装し、削除と復元を両立
- TailwindでシンプルなUI構築
- Renderを用いた本番デプロイ

## 開発背景
Webアプリ開発の基礎を理解するために、Laravelを用いたTodoアプリを作成しました。
単なるCRUDにとどまらず、実務でも利用されることを意識し、
削除データの復元機能（ゴミ箱機能）を実装しました。
